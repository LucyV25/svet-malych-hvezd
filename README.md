# Svět malé hvězdičky

Český web s pohádkami, čtecím dobrodružstvím a hravým procvičováním pro děti.

## Spuštění

Vyžaduje Node.js. V kořenové složce projektu spusť:

```sh
npm run story:serve
```

Server vypíše místní adresu. Web obsahuje také rozcestník, matematiku, češtinu, angličtinu, Minecraft, adventní kalendář a vlastní učivo.

## Ukládání

Oblíbené příběhy a vlastní učivo se ukládají podle nastavení jednotlivých stránek. Lokální soubor `data/favorites.json` není součástí veřejného repozitáře.
